# Blue Sentinel

## AI-Powered Early Warning & Environmental Response System

Blue Sentinel combines satellite data, environmental information,
AI/ML risk detection, GIS mapping, and citizen reports to identify
potential threats to coral reef ecosystems.

## Project Modules

- Frontend - User interface and dashboard
- Backend - APIs and application services
- AI/ML - Risk detection and prediction
- GIS - Interactive maps and spatial analysis
- Satellite Data - Satellite and environmental datasets
- Citizen - Citizen pollution reporting
- Docs - Project documentation
